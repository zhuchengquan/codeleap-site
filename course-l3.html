这个阶段的三道坎

孩子一定会卡住的地方

提前知道卡在哪，比事后抱怨「学不会」有用。

01IndentationError：代码「坏了」

看着像程序出错，其实只是缩进少了一格。孩子第一次知道代码对空格也较真，从此写代码会先对齐。

02IndexError：列表里没有这一项

下标从 0 开始，长度是 5 的列表最大下标是 4。让他先打印 len() 再访问，这个习惯能省掉一半的调试时间。

03能写出来，但讲不出为什么

问「为什么用列表不用十个变量」，答不上来就是没真懂。每次项目结束都要口头复述一遍思路。

常见问题

家长最常问的四件事

需要先学图形化吗？
不必须。9 岁以上、能独立完成 40 分钟专注任务的孩子可以直接从 Python 开始。测评会判断是否适合。
电脑有什么要求？
Windows 或 macOS 均可，能装 Python 3 就行，四年前的机器也够用。不需要独立显卡。
多久能做出一个完整游戏？
大约第 30 课时开始做 Pygame 小游戏，第 40 课时能拿出可玩版本。前面是必要的基础，跳过会卡在调试上。
和 GESP Python 怎么对应？
L3 的内容覆盖 GESP Python 一至二级的考点。想考三级的学员，通常需要再学一期专项，或在 L4 转 C++。
