竞赛路径

要不要打比赛？从 GESP 到 CSP-J/S 的完整路径

2026-11-26阅读约 9 分钟作者：陈昊

「竞赛」在家长群里被用得很宽：有人指 GESP 考级，有人指白名单比赛，有人指 CSP-J/S。三条路的门槛、投入和出口完全不同，混着说就会做错决定。这篇把路径、时间表和成本讲清楚，也讲清楚哪类孩子不该走。

先给结论：竞赛是一条有明确台阶的路，不是一次报名。它能被规划，也能被评估；可以中途退出，但退出得太晚，代价会落到文化课上。

一、先分清三类「比赛」

类型代表主办 · 对象它的作用
等级认证GESP 1–8 级CCF · 小学到初中为主能力凭证，高级别与 CSP 第一轮有衔接政策（以当年公告为准）
白名单赛事蓝桥杯青少组、NOC 等教育部白名单内的主办方 · 小学到高中作品与奖项，部分可作为综合素质材料
信息学奥赛CSP-J/S → NOIP → 省选 / NOICCF · 小学高年级可报 CSP-J含金量最高，难度也最大，直接关联升学履历

三者是台阶关系，不是并列选项：GESP 测「这一级的知识会不会」，白名单赛测「能不能做出一个完整作品」，CSP-J/S 测「在限时压力下能不能把算法写对」。不必三条都走，但要想清楚自家走的是哪一条。

二、路径与时间表

下面这条线是我们实际在用的，不是唯一走法，但每个节点都标了「这一步在验什么」，方便你判断孩子该不该往下走。

阶段（典型年龄）学什么这一步在验什么
图形化打底
6–9 岁		顺序、循环、条件、变量能不能把一件事拆成步骤，卡住时愿不愿意重试
Python + GESP 1–3
9–11 岁		代码语法、读报错、基础输入输出能不能独立写出完整程序，格式是否规范
C++ 入门 + GESP 4–6
10–12 岁		C++ 语法、数组、函数、简单算法能不能处理「有边界条件」的题，而不是照抄例题
CSP-J 第一轮 → 复赛
11–13 岁		算法专题、模拟赛、限时训练能不能在 3.5 小时内稳定拿分
CSP-S / NOIP
14–16 岁		图论、动态规划、数据结构数学与算法能否同时跟上，时间是否还够用

时间节点要记住两个：CSP-J/S 每年 9 月第一轮、10 月第二轮；GESP 每年 3、6、9、12 月各一场。这意味着任何一条路径的实际准备周期都是 6 到 12 个月，赛前两个月必须进入集训节奏——临时抱佛脚在信息学里几乎无效。

三、什么样的孩子适合走竞赛线

我们劝退过的孩子，比招进来的多。三个信号同时出现，才建议往竞赛方向走：

  • 数学不吃力。不是要提前学，而是当下学分数、负数、简单方程时不痛苦。CSP-J 复赛的题，本质是把数学关系翻译成代码。
  • 能接受「一道题改 40 分钟」。不是喜欢，是能忍。竞赛的日常是写完、错了、找错、再写，重复到对为止。忍不了这个循环的孩子，进竞赛班两周就会崩。
  • 对分数和排名有正向反应。看到自己从 40 分到 70 分会兴奋，而不是害怕下次掉下来。这一条决定了能不能扛过赛前的高压期。

反过来，三种情况不建议走：讨厌重复劳动（竞赛大量时间在改同一道题）、怕输且输不起（模拟赛每周排名）、时间已经被文化课和两个以上兴趣班占满（竞赛需要稳定的每周投入，插花式学习连第一轮都过不了）。

四、三种起跑线，走法完全不同

起点（约年龄）该怎么排现实目标
四年级
约 10 岁		能走完整路径：按上表按部就班，图形化可压缩到 16 课时六年级冲 CSP-J 复赛，初一冲提高级
六年级
约 12 岁		能走但要压缩：跳过图形化，Python 8 课时过渡后直接进 C++当年 CSP-J 拿分，第二年冲一等奖
初一起
约 13 岁		只剩效率路线：直接 C++ 强化，目标倒排，放弃「打基础」的慢节奏CSP-J 一等奖或 CSP-S 参与，为高中衔接

三条线里最容易出错的是第二条：六年级起步的家长最容易高估时间。看起来还有三年，实际上初二的分化期会吃掉一半精力，真正能全力投入的只有初一到初二上这一个学期。所以六年级起跑，第一年就必须见到 CSP-J 的分数，不能只「学着看」。

五、竞赛线的真实成本

成本项具体量说明
每周时间2 次课 + 每天 40–60 分钟练习赛前两个月加到每天 90 分钟，周末加模拟赛
课程投入L4 竞赛班 7980 元 / 期（48 次 × 120 分钟）从 C++ 入门到 CSP-J 复赛水平，通常需要 2–3 期
参赛与差旅报名费 + 异地参赛食宿第一轮多在本地，复赛视考点安排
机会成本与文化课、其他兴趣的取舍初二上学期是最集中的退出节点，多数家庭在这里做选择

关于回报要说实话：CSP-J/S 的一等奖名额按省划定，比例不高。投入两三年拿不到一等奖是常见结果，不是失败。所以决定之前要问自己一句：如果最后没拿奖，这段经历还值不值？如果答案是「不值」，那大概率不该走。

六、不走竞赛线，也能拿走三样东西

竞赛班的知识点，有一半是可以迁移的，跟拿不拿奖无关：

  • 读题与拆解。把一段 300 字的描述拆成「输入什么、约束是什么、要输出什么」，这个能力在数学应用题和物理题上直接生效。
  • 调试的耐心与方法。先定位、再假设、再验证——这套流程和修任何东西都一样，包括修自己的错题本。
  • 在压力下完成任务。限时训练带来的不是分数，是「时间不够时先拿能拿的分」的判断力。
我们内部有句话：竞赛班的真正产品不是奖状，是「遇到难题不慌」的肌肉记忆。奖状是副产品，有更好，没有也不亏。

七、我们的建议

家庭状态建议动作观察期
想试水，不确定孩子吃不吃得消先考 GESP 3 级，用一次真实考试判断抗压能力1 个季度
明确想走竞赛，孩子数学不弱做一次 C++ 起点测评，按 CSP-J 目标倒排课表直接进入路径
孩子有兴趣但家长拿不准先上一次校内模拟赛（3 小时限时），看赛后状态而不是看分数1 次
已经在竞赛班但连续两次模拟赛掉队回退到 Python 项目课，把兴趣先保住1 学期

最后提醒一句：竞赛是加速器，不是起跑线。没有兴趣和耐力做底，加速只会更早熄火。我们更愿意看到一个孩子在 L3 做完整项目、对代码有感情，而不是在竞赛班被排名磨到再也不想碰编程。
