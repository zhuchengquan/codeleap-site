# 码跃少儿编程 CodeLeap · 官网示例站

一个覆盖「少儿编程教育机构」完整商业链路的纯前端静态站点：从品牌主张、课程体系、师资、成果、定价，到报名流程、家长中心、校区到店、招生简章与政策条款。

> 这是一个**演示用示例项目**。文中机构名、地址、电话、师资、学员数据、价格、赛历均为示例内容，上线前必须替换为真实信息。

## 特点

- **纯静态**：只有 HTML + CSS + 原生 JS，无构建步骤、无框架、无第三方依赖（字体通过样式镜像外链）。
- **39 个可导航页面**，覆盖获客 → 信任 → 决策 → 交付 → 售后全链路；其中 9 个是「体系专题」页（课程×考级、平台与课堂、测评体系、作品与创作、教具与硬件、校区运营、备课与授课、招生与学员、家校沟通），另有 4 个家长自助工具页（`stage-finder.html`、`plan-calculator.html`、`level-test.html`、`study-mode.html`）、价格与优惠 `pricing.html`、全站内容地图 `site-map.html`、`404.html` 与存档页 `manual.html`。
- **iOS 液态玻璃视觉** + 洛谷式居中内容栏，支持明暗双模式（`localStorage` 记忆）。
- **内容营销**：10 篇家长决策向长文（几岁开始学 / GESP 一级备考 / Scratch 之后 / 班型怎么选 / 竞赛路径 / 数学与编程 / 试听课 / 线上课 / 不想学了 / 自学还是报班），按真实教学经验写成。
- 移动端适配：≤720px 有吸底预约条，全站锚点滚动补偿，图片 `srcset` + WebP 双档。
- **站内搜索 + 本页目录**：顶部放大镜（或 `Ctrl+K`、`/`）唤起玻璃搜索框，索引 298 条、覆盖 39 个页面的章节与正文摘要（`search-index.js` 为全站共用的一份索引，正文按节截取 320 字做关键词匹配），命中即跳转对应段落；≥1420px 页面右侧常驻本页目录，窄屏收在右下角按钮里。
- **四个家长自助小工具**：`stage-finder.html` 四道单选题（年级、编程经验、独立动手、数学进度）按公开 8 分制给出 L1–L4 建议起点与例外提醒；`plan-calculator.html` 按年级、基础、目标与每周次数，算出经过阶段、总课时、预计月数与线下线上两套价格，起点表、目标表与单价全部公开，四个工具互相跳转；`level-test.html` 是八道选择题（不用键盘）测孩子的逻辑底子，出得分、建议起点与错题清单，家长读题、孩子作答；`study-mode.html` 用五道题判断「自学 / 自学加少量付费 / 报班 / 先诊断」，按反馈、时序、卡点、节奏、班源五项给结论、逐条列出缺项与改判条件。

## 本地预览

直接双击 `index.html`，或在目录下起一个静态服务：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 部署到 GitHub Pages

1. 推到 GitHub 仓库（默认分支 `main`）。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。
3. 稍等片刻，访问 `https://<用户名>.github.io/<仓库名>/`。

## 上线前必须替换的内容

- 所有 `https://codeleap.example/` 域名（`canonical`、`og:url`、`sitemap.xml`、`robots.txt`）。
- 机构名称、校区地址、电话、微信、邮箱。
- 师资姓名与履历、学员统计数据、竞赛成绩。
- 价格、优惠规则、退费条款（需与真实合同一致）。
- 赛历日期（文中 2027 年的部分条目为按往年规律的**预计**，应以主办方公告为准）。
- 表单与支付：目前全部为前端演示，数据只写入浏览器 `localStorage`，未对接任何后端。

## 九页专题的组织方式

这九页不是把课程内容再讲一遍，而是补上「家长看不见、但决定信任」的部分。每一页回答一个具体问题，并且都写「我们不做/不能做什么」，把边界放在承诺前面。

| 页面 | 对应的问题 | 主要内容来源 |
| --- | --- | --- |
| 课程 × 考级 | 学完这个阶段，能考到哪一级、能参加什么比赛？ | L1–L4 大纲、GESP 一至八级、CSP-J/S 与白名单赛事 |
| 平台与课堂 | 孩子在电脑上到底做了什么？ | 账号体系、课堂留痕、工具用途、家长端可见范围、隐私规则 |
| 测评体系 | 怎么判断孩子真的学进去了？ | 四层测评、报告字段、OJ 题库、不达标时的处置 |
| 作品与创作 | 孩子做出了什么，作品归谁？ | 编辑器能力、发布流程、创意区规则、作品集标准、版权 |
| 教具与硬件 | 器材从哪来、坏了谁负责、安全边界在哪？ | 两套器材清单、开箱验收、使用规范、维护赔付、安全禁令 |
| 校区运营 | 一个校区怎么从签约走到开第一节课？ | 30 天阶段表、角色权限、课时规则、月度对账、支持 SLA、合作方式 |
| 备课与授课 | 一节课在上台前和台后发生了什么？ | 90 分钟切片、备课七步、教案八字段、四类课型、现场处置、课后 24 小时、资源七件套、12 个技术卡点 |
| 招生与学员 | 从一条线索到一个结业学员，中间有哪些环节？ | 八步生命周期、线索时限、试听转化、建档字段、分班原则、积分与流失 |
| 家校沟通 | 家长什么时候会收到什么，出问题找谁？ | 六个固定节点、三种家长会、微信规范、投诉时限、家庭配合 |

`operations.html` 面向校长与合作机构，页内三种合作方式已明确标注「不构成招商承诺、收益承诺或授权要约」，正式合作以书面合同为准。`_build/` 是这些页面的生成与校验脚本（`layout.mjs` 提供统一骨架，`p1`–`p15` 是内容模块，`gen-pages.mjs` 输出 HTML 并注入搜索入口与目录，`patch-index.mjs` 给首页装同一套搜索，`patch-all.mjs` 给其余手写页装搜索入口，`site-index.mjs` 汇总全站章节、`build-search.mjs` 生成全站共用的 `search-index.js`，`verify-pages.mjs` 与 `scan-links.mjs` 做标签、链接与 sitemap 校验），仅开发时使用，不参与站点运行。

## 招生简章 PDF 怎么重新生成

`brochure-print.html` 是排版源（5 页 A4，`@page size: A4; margin: 0`，每页固定 210×297mm），改完内容后在本机执行：

```powershell
chrome.exe --headless=new --print-to-pdf="brochure-2026-2027.pdf" `
  --no-pdf-header-footer "file:///.../brochure-print.html"
python _build\pdf-meta.py brochure-2026-2027.pdf brochure-2026-2027.pdf
```

字体用系统雅黑（`Microsoft YaHei`）而不再挂 CDN 中文字体，PDF 从 1.5MB 降到约 450KB；`_build\pdf-meta.py` 用 pypdf 写标题、作者、主题与关键词，顺带校验页数是否为 5。

## 关于 `manual.html`（第三方内容存档）

该页最初是把语雀公开知识库《5aqima 平台使用手册》（作者 尹登峰，协作者 双双、loumuu，建站方 奇码星球 / 编缘科技）整本抓取下来做的阅读页。**它不是本站的业务内容，也不是本项目的建站思路**，现降级为内部存档：

- 已从首页页脚、`sitemap.xml` 与主导航中移除入口，页面顶部加了「内部存档页」提示条，不再出现「预约试听」等营销入口。
- 页面加了 `<meta name="robots" content="noindex, nofollow">`，`robots.txt` 也 `Disallow: /manual.html`，搜索引擎不会收录。
- 原文共 69 篇、标称 72,745 字，页面逐篇保留标题、正文、操作步骤与截图；其中 7 篇在原文中只有标题、没有正文，按原样保留并标注。
- 143 张截图已下载到 `assets/manual/` 本地引用，避免外链失效。
- 版权归原作者与权利方所有；对外分发前须取得授权。正式上线时如不需要，可删除本页与 `assets/manual/` 目录。
