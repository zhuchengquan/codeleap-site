          GESP

          CCF 编程能力等级认证，一年四次，在 3、6、9、12 月各举办一次。图形化编程 1–4 级，Python 与 C++ 各 1–8 级；1–4 级考 2 小时，5–8 级考 3 小时。首次报名从 1 级开始，单级 90 分以上可跨一级报考。

          CSP-J/S

          CCF 非专业级软件能力认证，分 J（入门组）与 S（提高组）。第一轮为集中笔试，成绩优异者进入第二轮上机认证。这是信息学竞赛体系的第一道门槛，也是很多孩子第一次面对真正意义上的算法考试。

            常见问题

            家长最关心的几件事

            孩子零基础能学吗？
            可以。6–8 岁零基础从 L1 图形化编程开始，不需要认识英文单词或打字。课程按认知发展设计，第一节就能做出会动的动画。
            学编程会不会影响学业？
            每周 1 次课、课后 20 分钟以内的练习。编程训练的拆解问题与调试习惯，对数学应用题和物理学习都有正向帮助。我们不建议在孩子已经明显超负荷时再加课，顾问会在试听时如实给出建议。
            先学 Scratch 还是直接学 Python / C++？
            9 岁以下建议从图形化开始，先建立"我能做出来"的信心；9 岁以上、有较强阅读与打字能力的孩子可以直接进 Python；11 岁以上目标是竞赛的孩子，通常需要 Python 或图形化的基础再进入 C++。
            GESP 和 CSP-J/S 是什么关系？
            GESP 是中国计算机学会的编程能力等级认证，分图形化、Python、C++ 三个方向，适合阶段性检验；CSP-J/S 是信息学奥赛的入门级与提高级认证，是竞赛通道的入口。GESP 达到一定等级可免除 CSP-J/S 的初赛。
            线上课和线下课怎么选？
            同一套教研、课件和作业体系。线下课有更集中的课堂氛围和当面指导；线上课省去通勤，适合距离远或时间紧的家庭。启蒙段孩子我们更推荐线下。
            缺课怎么办？
            线上课有回放可随时补看；线下课可预约同期平行班补课，或转为线上课补课。每学年有 4 次免费补课额度。

            退费规则
            前两次课不满意，全额退款（含教材与平台使用费）。从第三次课起申请退费，按未消耗课时比例退还，已消耗课时与已发放教材按实际成本结算。退费申请自受理起 7 个工作日内办结，原路退回。
            转班规则
            同一阶段内可免费转班一次，需在开课前 3 天提出，视目标班次余位安排。跨阶段转班（例如从 Python 转到 C++）需重新测评，按测评结果确定入班阶段。
            补课与请假
            每学年提供 4 次免费补课。请假需在上课前 4 小时通过顾问或家长端提交，未提前提交视为缺课，计入课时消耗。线上课全部有回放，可随时补看。
            课时有效期
            学年课时有效期为 12 个月，自首次上课起算。因升学、搬迁等原因可申请延期一次，最长延长 3 个月，延期期间不占用新学年课时。
