Scratch 学完之后去哪？三条路线的真实区别

2026-11-23阅读约 8 分钟作者：王雨晴

孩子 Scratch 学了两年，作品做得挺像样，接下来呢？这是家长最常卡住的地方。市面上有三种说法，都说自己对。这篇不劝你选哪条，只把三条路各自的代价讲清楚。

先说一句不太讨喜的话：Scratch 学两年之后，如果还在「做一个更好看的 Scratch 作品」，边际收益已经很低了。图形化的天花板不在工具，在于它刻意隐藏了所有工程细节。所以问题不是要不要走，而是往哪走。

一、先用三个信号自查

  • 孩子对「代码长什么样」的反应。给他看一眼 Python 代码，是「这什么鬼」还是「我能试试」。前者说明还没到转真代码的时机，硬转只会消耗兴趣。
  • 数学底子。分数、负数、取余这三个概念能不能用。Python 的列表下标从 0 开始、用取模判断周期性，都吃这个基础。
  • 目标是作品还是成绩。想做游戏、做工具，走 Python；想拿竞赛成绩、走升学材料，走 C++。这两个目标的技术栈从第一天就分叉，走错要重来。

三个数字值得注意：课时都是 48；价格差在 L4（每次 120 分钟、8 人班、含 OJ 账号与模考讲评）；出口差别最大的是 L4——CSP-J 一等奖在部分地区是实打实的升学材料，而 Python 的出口是能力和作品，不能直接换成分数。

三、为什么我们不让 9 岁孩子直接上 C++

每年都有家长问：反正最后要考 CSP，为什么不早点学 C++？原因是 C++ 的前置门槛不在语法，在数学和抽象：

  • 要先能「看见」内存。数组越界、指针、浮点误差，这些概念要求孩子能在大脑里画出一块内存的样子。这个能力通常在 11 岁前后才稳定。
  • 竞赛题的核心是数学建模，不是写代码。小学四年级以下的数论和组合基础，通常不足以支撑 CSP-J 的前两题。
  • 学习曲线太陡。前 10 课时几乎都在处理编译错误和格式问题，对耐心的消耗极大，很容易把兴趣磨掉。

我们见过最典型的失败：9 岁转 C++，前三周哭着来上课，两个月后回退到 Python，前后浪费一个学期。所以我们的分界线是两个条件同时满足：11 岁以上，且能用分数和负数做运算。缺一个都建议先补。

四、转 Python 的第一个月会发生什么

说实话：会不适应。图形化里拖一个「重复 10 次」，代码里要写 for i in range(10)，孩子第一次要同时记语法、拼写和缩进。第一个月最常见的三个崩溃点：

  • 缩进报错。报 IndentationError，孩子看不出哪里错——因为空格是看不见的。这一关通常要 3 到 5 次课才过。
  • 名字拼错。报 NameError，孩子第一反应是「程序坏了」，而不是「我打错字了」。
  • 不会读报错。这是最关键的坎。我们的做法是让孩子练「只读最后一行」——报错的最后一行永远告诉你是什么错，前面全是路径。

能过这三关的孩子，通常在转 Python 的第 6 到 8 次课会突然「通」——开始主动看报错、自己改。这个瞬间比任何作品都值得记录。

五、转轨前该补的三项基本功

决定转 Python 之后，别急着开课。有三项能力在图形化阶段很容易被绕过，但一进代码就天天要用，提前两三周补，比开课后边学边补省力得多。

基本功为什么现在补怎么练（每天 15 分钟）
键盘输入图形化只需拖拽，代码要一个字母一个字母敲。打字慢的孩子，一道题光输入就耗掉一半时间指法练到每分钟 20 个字符以上，只要求准，不要求快
读英文关键词报错、函数名、题目条件里全是英文。不要求背单词，要求「看到能认出来」把 print / input / for / if / range 写在便签上，每天认一遍
照抄再改图形化里改一个参数就能看到效果，代码里要先能完整抄对一段，再动手改给一段 8 行的示例代码，要求一字不差抄进编辑器并跑通，再改一个数字观察结果

三项里最重要的是第三项。能抄对，说明他开始注意细节；能改对，说明他理解了这段代码在做什么。这两步走顺了，第一个月的挫败感会少一大半。

六、四条常见误判

转轨这件事上，家长和孩子的判断经常被四个印象带偏，逐条拆开说。

  • 「他会做作品，就是会编程了。」作品能跑通，可能只是记住了步骤。换个检验方式：把作品删掉一半，让他自己补回来。补得出，才算懂。
  • 「图形化是低幼玩具，学着浪费时间。」8–10 岁用图形化做带变量、列表、广播的项目，思维难度不低于背语法。真正的浪费是原地重复已经会的东西，不是工具本身。
  • 「Python 学得慢，是不是不适合？」第一个月的慢，九成来自输入速度与读报错，不来自理解力。这两样都可训练，跟天赋无关。
  • 「不打比赛就等于没学。」竞赛是出口之一，不是唯一出口。想走工程方向的孩子，把项目做深、把代码写规范，同样有价值。把所有孩子都往赛道上赶，多数会在初二那年集体放弃。
一句话总结：Scratch 之后的选择，本质是选出口，不是选语言。想让孩子「会做东西」走 Python，想让孩子「拿成绩」走 C++，想让孩子「玩得更好」继续图形化也不算浪费。
